Serverul rulează

Craftelite — License Server

Nu este o pagină publică — doar endpoint-uri API.

  • GET /api/check?domain=...
    verificare licență (public)
  • POST /api/admin/license
    creează / reînnoiește o licență (necesită header x-admin-secret)
  • POST /api/admin/revoke
    revocă o licență (necesită header x-admin-secret)
